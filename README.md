# Code Stats

расширение для vs code, которое показывает статистику открытого файла.

## возможности

- подсчёт общего количества строк;
- подсчёт пустых и непустых строк;
- подсчёт слов;
- подсчёт символов.

## пример использования

1. открыть любой текстовый файл в vs code.
2. открыть палитру команд сочетанием `cmd + shift + p`.
3. найти команду расширения Code Stats и запустить её.
4. посмотреть статистику файла в открывшемся окне.
